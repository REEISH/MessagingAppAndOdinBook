# Social Network App

A full-stack social media application where users can share content, build their network, and communicate in real time.

##  Live Demo

**Try it out here:** [Messaging App](https://loquacious-cascaron-3b9a99.netlify.app/auth)

##  Features

* **Public Posts:** Users can create and share posts containing both images and text publicly.
* **User Discovery:** Search functionality to easily find and view other users on the platform.
* **Social Networking:** Follow and unfollow other users to curate your personal network.
* **Real-time Messaging:** Send and receive direct messages with other users in real time.

##  Tech Stack

**Frontend:**
* HTML
* React
* Tailwind

**Backend:**
* Node
* Express
* PostgreSQL
